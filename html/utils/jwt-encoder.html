JWT Encoder

Builds and signs a token entirely in your browser via the Web Crypto API — the secret never leaves this page. Supports HS256 / HS384 / HS512 (read from the header's alg). RS/ES algorithms need an actual key pair, which is a different, riskier workflow than a paste-and-sign tool should offer.
